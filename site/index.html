True colour for the apps that need it.

Figma, Photoshop and other colour-critical apps pause DuskMode on their own. Bring one to the front and your colours come back. For any other app, flip one switch. Dimming stays on, so switching never flashes bright.

Invisible on calls.

The filter is applied at the display, after anything captures the screen. Zoom, Meet and screenshots get normal colours while you keep the warm ones.

Tested with Apple's ScreenCaptureKit: a white pixel reads 255, 255, 255 with the filter on.

public static func kelvin(forWarmth warmth: Double) -> Double {    let w = min(1, max(0, warmth))    return neutralKelvin - w * (neutralKelvin - minKelvin)} /// Per-channel multiplier (each 0…1; red is always 1) for a colour temperature.public static func multiplier(forKelvin kelvin: Double) -> (r: Double, g: Double, b: Double) {    let raw = blackbody(kelvin)    let ref = blackbody(neutralKelvin)    return (min(1, raw.r / ref.r),            min(1, raw.g / ref.g),            min(1, raw.b / ref.b))}
